顺手做的小工具

都是被某件具体的事烦到之后写的，不是练手项目。

windows-disk-cleanup

Windows 磁盘清理。按「删了会不会丢东西」分三级安全模型，默认只读扫描， 路径白名单挡住误删——不碰回收站、文档、照片。

Python · 纯标准库 · 18 个测试

bili-watcher

B 站订阅与内容摘要。Node 只读引擎加 Chrome MV3 扩展， MD5 与 WBI 签名自己算，只读公开数据。

Node · Chrome 扩展 · CI 校验签名算法

photo-cleanup-pipeline

手机照片整理。SHA-256 精确去重、HEIC 转码与假 JPG 识别、 pHash 相似图报告，删除走清单不自动执行。

Python · 清单式安全删除

windows-healthcheck

Windows 一键体检。只读 PowerShell 诊断脚本集， 覆盖硬件、启动项、安全、稳定性与显卡驱动，一键生成留档报告。

PowerShell · 全程只读
